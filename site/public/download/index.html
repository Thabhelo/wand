What’s new in build 23?

Wand now keeps its connection keys together in Keychain. On our test Mac, it reconnected without another password prompt after restarting the app, updating it, and rebooting the Mac. Existing users may need to approve Keychain access once during migration.

How to install

  1. Download and open the disk image.
  2. If Wand is already running, quit it first. Replace the existing Wand app in its current folder, or drag it into Applications for a new installation. Then open Wand.
  3. If macOS blocks it as an unidentified developer, open System Settings → Privacy & Security. Find Wand and choose Open Anyway, then confirm. Only approve the app you downloaded here. Do not disable your Mac’s security protections.
  4. In Wand, open Connection. If prompted for Keychain access, enter your Mac login password in the macOS dialog and choose Always Allow if you trust this Wand build and want to remember access. Never enter it on a website.
  5. Click Connect and sign in with Google to link your Mac.

If you dismissed the Keychain dialog, click Allow Keychain access in Wand to request it again.

What works in the beta?

Checking your Mac’s status, controlling music and volume, opening apps and websites, closing apps, and running Shortcuts you approve.

Desktop-control beta

Wand includes desktop-wide access after one-time setup: app inspection, text entry, clicks, scrolling and optional window images. Access stays enabled until paused. This is experimental; real-app compatibility and Muse integration are still being tested. Basic Mac controls are included.
